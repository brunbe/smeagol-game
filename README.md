# Sméagol's Precious

A browser-based canvas game about Sméagol collecting his beloved rings while avoiding the Eye of Sauron.

## How to play

1. Open `index.html` in any modern browser (no server needed).
2. Use **Arrow keys** or **WASD** to move Sméagol around the map.
3. Collect every golden **ring** (◈) on the level to advance.
4. Avoid the red **Eyes of Sauron** — each touch costs a life.
5. You start with **3 lives**. Lose them all and it's Game Over.
6. There are **5 levels**, each with more and faster enemies. Collect all rings on level 5 to win!

## Files

| File | Description |
|---|---|
| `index.html` | Game shell, HUD and canvas |
| `style.css` | Dark-fantasy visual styling |
| `game.js` | All game logic: movement, ring collection, enemy AI, rendering |
